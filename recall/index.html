    Google Drive sync

    How to get a Client ID (free, ~10 minutes, once)
    1. Go to console.cloud.google.com and create a project (e.g. “Recall”).
    2. Open APIs & Services → Library, search Google Drive API, click Enable.
    3. Open Google Auth Platform (OAuth consent screen): choose External, fill in app name and your email. Under Audience, add your own Gmail as a test user.
    4. Go to Clients → Create client → type Web application. Under Authorized JavaScript origins add:
    5. Copy the Client ID and paste it above, then tap Connect & sync now.

    Recall only asks for access to files it creates itself (a folder called “Recall Notes” in your Drive). It can't see your other files.
